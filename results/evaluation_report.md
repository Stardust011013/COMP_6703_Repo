# Stress resilience 回归：验证集结果

## 数据与模型

- 训练：40 位参与者的 EEG 与 label.csv 分数。
- 验证：10 位未参与训练的参与者；生成预测后才读取 val.csv 评分。
- 输入：每个 MAT 信号的后 128 行（第 2–129 行）。
- 模型：随机森林；每人输出一个 0–40 的分数。
- 本报告使用 validation_predictions.csv 中保留六位小数的预测值。

## 计算方法

记真实分数为 yᵢ、预测分数为 ŷᵢ、误差为 eᵢ = yᵢ − ŷᵢ。这里 n = 10，真实分数均值 ȳ = 25.9。

RMSE（均方根误差）= √[Σ(yᵢ − ŷᵢ)² / n]。它先平方每人的误差、求平均，再开平方；单位仍是分数点，越低越好。

- 平方误差和 SSE = Σ(yᵢ − ŷᵢ)² = 527.470663。
- MSE = SSE / 10 = 52.747066。
- **RMSE = √52.747066 = 7.262718 分**。

R²（决定系数）= 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²。分母是以这 10 人的真实分数均值作常数预测时的平方误差和。R² = 1 表示完美预测；0 表示与该常数预测相同；负值表示更差。

- 真实分数平方离差和 SST = Σ(yᵢ − ȳ)² = 690.900000。
- **R² = 1 − 527.470663 / 690.900000 = 0.236546**。

补充：MAE = Σ|yᵢ − ŷᵢ| / 10 = **5.611859 分**。

## R² 与相关系数的区别

Pearson 相关系数 r = corr(y, ŷ) = 0.658724；它的平方 r² = 0.433917。
本报告的回归 R² = 0.236546，直接比较真实分数与预测分数的平方误差；两者在独立验证集上一般不相等。
r 衡量两组分数是否一起升降，不检验预测值是否校准。例如给全部预测值加一个常数，r 不变，但回归 R² 会变。
例如，在带截距的普通最小二乘回归的训练样本上，R² 等于 corr(y, ŷ)²；只有一个自变量时，也等于 corr(x, y)²。
